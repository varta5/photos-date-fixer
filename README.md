# photos-date-fixer

Have a bunch of nice photos with incorrect date or time stored in its metadata? No worries! This utiliy is here to the rescue!

Change the date and time metadata of all the photos in a directory.

This project is under development!

## Usage

Run the fix_dates.py with Python interpreter:

```shell
python fix_dates.py
```

The script counts the number of photo files (\*.jpg or \*.jpeg) in the current directory.
